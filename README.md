# 🎓 Student Information System

<p align="justify"> I implemented the <B>Student Information System</B> by using the C++ programming language in command-line interface. That system was designed to manage student records, course enrollments, and administrative tasks, which helps to Administrators, staff, and students use it to access information with role-based login options.
  
The project demonstrates **file handling, structures, and menu-driven programming** in C++.  </p>
 

---

## 📌 Features

### 👤 Administrator
- Add New Student Records
- Add New Course Details
- View New Student Records
- View Student Enrolled Records
- View Course Roster

### 👤 Staff
- View New Student Records
- View Student Enrolled Records
- View Course Roster

### 👤 Student
- Enroll In Course
- Withdraw From Course
- Enroll and Withdraw Course

### ➕ Additional
- Role-based login system with username and password
- File-based storage for persistence (`student.txt`, `enrolled.txt`, course-specific text files)
- Menu-driven interface for easy navigation

---

## 🛠️ Technologies Used
- **Language:** C++
- **File Handling:** `.txt` files for storing students, courses, and enrollment data
- **Data Structures:** `struct` for student, course, and login details
- **Console UI:** Menu-driven interaction using `cin`, `cout`, and formatted output (`iomanip`)

---

## 🎮 How to Run ?

1. Download or clone this repository.
2. Open the project folder in Dev C++ (or any C++ IDE).
3. Compile and run the program.
